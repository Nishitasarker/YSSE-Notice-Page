# YSSE Notice Page | Web Development & CMS Wing

This project is part of the **YSSE IT Department (Web Development & CMS Wing) Week 2 Task Assignment**. The goal is to build a clean, structured, and semantic Notice Page using **HTML5** as part of the future YSSE Main Portal.

---

##  Project Overview

The webpage serves as an official announcement board for the Youth School for Social Entrepreneurs (YSSE). It showcases proper use of semantic HTML elements, accessible links, a structured tabular summary of notices, and a professional layout without relying on CSS or JavaScript (as per assignment instructions).

---

##  Built With

* **HTML5** — Core markup language utilizing semantic tags.
* **VS Code** — Development environment.
* **Web Browser** — For rendering and testing.

---

##  Project Directory Structure

```text
ysse-notice-page/
├── index.html        # Main HTML document containing the notice board structure
└── README.md         # Project documentation

📑 Key Features & Semantic Elements Used

<header> & <h1> to <h2>: Used for establishing a clear document outline and page identity for YSSE.

<nav>: Contains accessible navigation links representing different sections of the portal.

<main>: Wraps the primary content area of the document.

<section>: Divides the page into logical thematic blocks (Notices, Table, Useful Links).

<article>: Encapsulates each independent sample notice item.

<table>, <thead>, <th>, <caption>: Organizes notice summaries cleanly into tabular format with correct accessibility tags.

<footer>: Contains copyright information and contact details.

 How to Run the Project Locally
Clone the repository or download the project files.

Open the project folder in VS Code.

Open index.html in any modern web browser (Google Chrome, Firefox, Edge, etc.) or use the Live Server extension in VS Code to view the live preview.
